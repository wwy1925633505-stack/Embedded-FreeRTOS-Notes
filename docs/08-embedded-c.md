# 08. 嵌入式 C 与内存安全

## 1. 对象生命周期

- 自动变量：离开作用域后失效，不能把其地址交给异步任务长期使用。
- 静态变量：生命周期贯穿程序运行，但需考虑并发访问和可重入性。
- 动态对象：必须定义所有权、释放者和异常路径。
- DMA 缓冲区：传输完成前不得复用或释放。

## 2. `volatile` 的正确边界

适合使用：

- 内存映射外设寄存器。
- 被 ISR 与主流程共享、且平台保证单次访问原子的简单标志。
- 会被硬件异步修改的内存位置。

它只能阻止编译器省略或合并相应访问，不能保证复合操作原子性，也不能建立任务间同步关系。

## 3. 整数与边界

- 协议字段使用 `<stdint.h>` 的明确宽度类型。
- 长度参与加法前检查是否溢出。
- 比较有符号和无符号数时显式转换并说明范围。
- 位移前确认位数小于类型宽度。
- 解析外部输入时先验证长度，再访问字段。

```c
if ((payload_len > MAX_PAYLOAD) ||
    (payload_len > (buffer_len - HEADER_SIZE))) {
    return PARSE_BAD_LENGTH;
}
```

前提是已确认 `buffer_len >= HEADER_SIZE`，避免无符号减法下溢。

## 4. 结构体与对齐

结构体大小可能包含填充字节。不要直接把内存中的结构体当成跨设备协议帧发送，否则会受到对齐、字节序和编译器布局影响。应逐字段序列化。

## 5. 防御式接口

- 指针参数先检查 `NULL`。
- 缓冲区与容量同时传入。
- 返回明确错误码，不用一个布尔值隐藏多种失败原因。
- 输出参数只在成功时更新，或在文档中明确部分更新语义。
- 在模块边界使用 `const` 表达只读意图。
