# 07. UART、CAN、SPI、I²C

## 1. 协议对比

| 协议 | 时钟 | 典型拓扑 | 全双工 | 关键工程问题 |
| --- | --- | --- | --- | --- |
| UART | 异步 | 点对点 | 是 | 波特率误差、帧边界、缓存溢出 |
| CAN | 异步总线 | 多节点 | 否 | 仲裁、过滤器、错误计数、总线负载 |
| SPI | 同步 | 一主多从 | 是 | CPOL/CPHA、片选时序、字节序 |
| I²C | 同步开漏 | 多节点 | 半双工 | 地址、上拉、电容、ACK、总线恢复 |

## 2. UART 帧协议

UART 只提供字节流，不提供应用帧边界。常见帧格式：

```text
SOF | Version | Length | Command | Payload | CRC16
```

解析器应支持：

- 分段到达和一次到达多帧。
- 错误长度拒绝和 CRC 校验。
- 噪声后重新寻找帧头。
- 超时清理半包。
- 未知命令返回明确错误。

## 3. CAN 接收链路

推荐链路：CAN RX IRQ → 读取 FIFO → 队列发送完整帧 → 任务按 ID/序号组包。

排查丢帧时分层计数：

1. CAN 分析仪确认总线实际帧数。
2. 统计硬件接收和 FIFO 溢出。
3. 检查 ISR 入队返回值与队列高水位。
4. 核对组包序号、超时、长度和不同 ID 的上下文隔离。
5. 根据协议决定整包作废、补包或请求重传。

## 4. SPI

- CPOL 定义空闲电平，CPHA 定义在哪个边沿采样。
- 主从必须使用相同模式、位宽和字节序。
- 片选的建立/保持时间要满足从设备手册。
- DMA 收发时注意 SPI 的发送与接收通常同时发生。

## 5. I²C

- SDA/SCL 为开漏，需要合适的上拉电阻。
- 上拉过大导致上升沿慢，上拉过小增加功耗和灌电流。
- 处理 NACK、仲裁丢失、时钟拉伸和 Busy 卡死。
- 总线恢复可尝试切 GPIO 输出 SCL 脉冲并生成 STOP，具体流程需符合器件要求。
